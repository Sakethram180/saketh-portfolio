    Project at GGST Innovations

    Ventures

    Real Estate · Android Application

    Overview

    Ventures is a real-estate Android application designed to simplify property discovery, buying, renting, selling, and property management. The platform supports multiple user roles, including landlords, tenants, agents, and administrators.

    My role

    Worked on Android application development, UI implementation, API integration, property-related workflows, navigation, location-based functionalities, debugging, and feature development.

    Concept mockups for illustration, not actual app screens.

    Key features

    • Multi-role access for landlords, tenants, agents and administrators
    • Property listings for rent, buy, sell and commercial categories
    • Location-based property discovery with address autocomplete
    • Google Maps integration for visualizing property locations
    • Property submission, approval and rejection workflows
    • Agent assignment based on property location
    • Authentication and user access management
    • Messaging and media upload functionality

    Technology stack

    KotlinJavaAndroidRetrofitREST APIsGoogle Maps

    Development challenges & solutions

    Four roles, one appChallenge · Each role needs different screens and actions.Solution · Structured navigation and access handling so each user sees only the flows that apply to them.
    Location-based discoveryChallenge · Properties had to be found and shown by place, not just by text.Solution · Integrated Google Maps and address autocomplete to visualize locations and reduce manual address entry.
    Approval workflow statesChallenge · Listings move between submitted, approved and rejected.Solution · Connected the screens to the REST APIs so each status change is reflected clearly in the UI.
    Matching agents to propertiesChallenge · Agents should be assigned according to where a property is.Solution · Worked with location data and API responses to support location-based agent assignment.
